# AI Store Intelligence System

## Overview

AI-powered CCTV analytics platform for retail stores that transforms raw surveillance footage into actionable business intelligence.

The system leverages Computer Vision, Object Tracking, Event Processing, and Real-Time Analytics to monitor customer movement, detect anomalies, and generate operational insights.

## Features

* Person Detection using YOLOv8
* Multi-Object Tracking using ByteTrack
* Event Generation Engine
* Real-Time Analytics APIs
* Crowd Monitoring
* Dwell Time Analysis
* Interactive Dashboard
* PostgreSQL Storage
* Dockerized Deployment
